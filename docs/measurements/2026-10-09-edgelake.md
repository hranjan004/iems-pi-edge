Raw method and results behind the figures in [03-memory-budget.md](../03-memory-budget.md).

## What was run

| Item | Value |
|---|---|
| EdgeLake | `EdgeLake/EdgeLake` branch `main` at `faba50ddf8ee` (2026-06-29). Package version 2.0.2606, node reports 1.4.2604 |

## Dependencies actually needed

Starting from an empty virtualenv and adding packages until the node started gave this
set: pyyaml, requests, psutil, orjson, cryptography, PyJWT, python-dotenv,
python-dateutil, pytz, netifaces, pyOpenSSL, dnspython, paho-mqtt, cython, web3 and
pycomm3. `web3` and `pycomm3` are imported unconditionally at startup even though
this node uses neither. The remaining packages in EdgeLake's `requirements.txt`
(grpc, opencv, av, yt-dlp, boto3, pymongo, kafka-python, opcua, pymodbus, the
anthropic SDK and mcp) are not needed. The MCP endpoint at `/mcp/sse` is served by
EdgeLake's own REST server and answered with them absent.

All 4,800 published rows were queryable in the day's partition table when the run
ended, so `write_immediate` inserts rows as they arrive and the file threshold does not
delay them. Querying the parent table returns nothing, the same behavior as AnyLog.

The Cortex-A53 in the Pi 3 is several times slower per core than the test machine, so
CPU on the Pi will be higher. RSS should be similar because it is dominated by Python
objects, not by architecture.

### The archive finding

With `write_immediate` on, which is the default and what keeps data fresh, EdgeLake
moves every processed JSON file to its archive directory regardless of `ARCHIVE=false`.
This is visible in `edge_lake/members/aloperator.py`, where the immediate path calls
`archive_file` unconditionally when the node is not a distributor. The archive is then
cleaned by a daily job that deletes files older than `ARCHIVE_DELETE` days, default 30.

Left at the defaults, a 2 KB threshold and 30-day retention would hold roughly 8 GB of
tiny files. The Pi configuration raises the threshold to 100 KB and sets
`ARCHIVE_DELETE=2`, which keeps the archive near 20 MB and also leaves two days of
compressed raw readings that can be replayed if the database is lost.
